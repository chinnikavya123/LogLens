
# 🚀 LogLens – Intelligent Log Analysis & Incident Investigation Platform

<p align="center">
  <strong>🔍 Making Log Analysis and Incident Investigation Simpler</strong>
</p>

LogLens is a browser-based log analysis platform designed to simplify application log monitoring and incident investigation. It helps developers explore application logs, identify errors, detect unusual patterns, investigate potential root causes, and compare log files through a clean and interactive dashboard.

The application processes log files directly in the browser, making log analysis simple without requiring a backend setup.

---

## ✨ Features

### 📊 1. Overview Dashboard
- View total logs and severity-wise statistics.
- Monitor critical errors, errors, and warnings.
- Visualize log distribution.
- Track application health score.
- View recent log activity.

### 🔎 2. Log Explorer
- Upload `.log` and `.txt` files.
- Search and filter log entries.
- Filter logs by severity and source file.
- Navigate through logs using pagination.
- Mask sensitive information displayed in log messages.

### 🚨 3. Incident Center
- Identify and group related log events.
- Explore incident timelines.
- Correlate events to understand possible connections.
- Detect recurring error patterns.
- Filter and sort incident information.

### 🧠 4. Anomaly Detection
- Analyze logs to identify unusual patterns.
- Highlight suspicious log activity.
- View anomaly summaries and findings.
- Use rule-based analysis to identify potential issues.

### 🛠️ 5. Root Cause Investigator
- Examine log patterns and error information.
- Identify potential causes of application issues.
- Present findings to support further investigation.

### 🔄 6. Compare Logs
- Upload and compare two log files.
- Identify differences between log entries.
- Analyze changes across log files.

### 📄 7. Reports
- Generate summaries of analyzed logs.
- View important statistics and investigation findings.
- Download reports for future reference.

## ⚙️ Getting Started

### 📌 Prerequisites
- A modern web browser.
- Visual Studio Code (recommended).
- Live Server extension (recommended).

### 🚀 Run Locally

**1. Clone the repository**

```bash
git clone https://github.com/chinnikavya123/LogLens.git
```

**2. Navigate to the project directory**

```bash
cd LogLens
```

**3. Open the project in Visual Studio Code**

```bash
code .
```

**4. Launch the application**

Open `index.html` using the Live Server extension, or open the file directly in your browser.

🎉 The LogLens dashboard is now ready to use!

## 📖 How to Use

1. Open the LogLens dashboard.
2. Upload one or more application log files.
3. Explore log entries using search and filters.
4. Review incident patterns and run anomaly detection.
5. Investigate potential root causes.
6. Compare log files when required.
7. Generate and download analysis reports.
